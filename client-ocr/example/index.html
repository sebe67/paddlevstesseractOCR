id-ocr-web demo

Pick a front image (and optional back image) of an already cropped/edge-straightened ID scan, then click "Run OCR". This calls the same runIdOcr / mergeIdOcrResults functions your app will use — see ../README.md for how to wire them into a real app. Requires the idscan_ocr bucket's model files to be public-read (see README setup step 1) for OCR to actually run; the page itself will load regardless.
